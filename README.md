# anki-card — بناء حزمة بطاقات Anki من PDF + CSV

مشروع بناء بطاقات فلاش كارد (Anki) شاملة من قاموس ورقي (PDF، الكلمات المستهدفة معلّمة بالأحمر) وملف كلمات (CSV).

## العينة الجاهزة الآن
- 📦 **ملف الاستيراد:** [`output/sample_deck.apkg`](output/sample_deck.apkg) — افتحه في Anki مباشرة (File → Import).
- 🖥️ **معاينة البطاقات:** افتح مجلد `preview/` أو شغّل `python3 -m http.server` داخله — أو استخدم أمر الخادم أدناه.
- 📋 **الخطة المفصلة بالمراحل:** [`PLAN.md`](PLAN.md)

### محتوى العينة (3 بطاقات × 2 بطاقة = 6 بطاقات فعلية)
| الكلمة | النوع | ماذا تُظهر |
|---|---|---|
| produce | كلمة (فعل/اسم) | جدول المشتقات الكامل كما في مثال العميل (12 صيغة) + صورة |
| umbrella | اسم مادي | الصورة التوضيحية + المعنى المجازي |
| give up | فعل مركّب | وراثة تصريف الفعل الأصلي + ملاحظة فنية |

كل بطاقة تضم: الوجه الأمامي إنجليزي بالكامل، وظهرها بجميع المعاني العربية، التعاريف الإنجليزية، المرادفات، الصوت، أمثلة مع ترجمتها، جدول الاشتقاقات، وملاحظات.

## خريطة المستودع
```
data/cards.json            ← مصدر البيانات الوحيد (يُبنى منه كل شيء)
data/input_format_sample.csv ← صيغة ملف الكلمات المقترحة
pipeline/build_deck.py     ← بناء ملف .apkg (genanki)
pipeline/validate.py       ← فحص الجودة الآلي قبل البناء
pipeline/render_preview.py ← توليد صفحة المعاينة
pipeline/fetch_media.py    ← هيكل جلب الصوت من المصادر في مرحلة الإنتاج
media/                     ← الصوت والصور
output/sample_deck.apkg    ← الحزمة النهائية الجاهزة للاستيراد
preview/                   ← معاينة مرئية تفاعلية
```

## التشغيل
```bash
pip3 install --break-system-packages genanki
python3 pipeline/validate.py      # فحص الجودة أولاً
python3 pipeline/build_deck.py    # بناء الحزمة
python3 pipeline/render_preview.py
cd preview && python3 -m http.server 8080 --bind 0.0.0.0   # معاينة البطاقات
```
